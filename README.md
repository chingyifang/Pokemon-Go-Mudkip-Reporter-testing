# 💧 Mudkip (#258) Spawn & IV/CP Guide 

A lightweight, bilingual (Traditional Chinese / English) web tool built for *Pokémon GO* trainers to quickly check Mudkip's wild spawn conditions, nest habits, shiny appearance, and 100% IV CP values.

## ✨ Features 
* **🌐 Bilingual Support :** Switch seamlessly between Traditional Taiwanese and English with a single click.
* **✨ Shiny Preview :** Toggle between regular and Shiny Mudkip official artwork.
* **🌍 Spawn & Nest Info:** Quick reference for Rainy weather boost, park/water biomes, egg pools, and evolution candy requirements.
* **📊 Interactive 100% IV CP Chart :** Filter 100% IV (15/15/15) CP values by encounter type (Field Research Lv.15, Egg/Raid Lv.20, Weather Boost Lv.25, Max Wild Lv.30/35) plus Swampert PVP IV tips.
